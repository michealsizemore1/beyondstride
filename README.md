# BeyondStride

Running app for Galaxy Watch (Wear OS) + Android phone: Stryd/H10, heart-rate zones, readiness, LiveTrack, trails, nutrition and Activities. (Disconnected from My Life Command Center in Nov 2026.)

Install from the latest release: `BeyondStride-PHONE.apk` on the phone, `BeyondStride-WATCH.apk` on the watch (via Wear Installer).
